# Frontend Project Instructions

This directory contains the React/TypeScript frontend application for the FreikerDialBot Automation project.

## Technologies Used:
- React
- TypeScript
- Vite (build tool)
- Tailwind CSS (for styling)

## Development Guidelines:
- Adhere to React best practices and functional components.
- Use TypeScript for type safety.
- Follow the existing component structure and styling conventions.
- Ensure all new components are tested.

## Available Scripts:
- `npm install`: Install dependencies.
- `npm run dev`: Start the development server.
- `npm run build`: Build the application for production.
- `npm run lint`: Run linters.

## Project Structure:
- `src/`: Main application source code.
- `src/pages/`: React components for different pages.
- `src/components/`: Reusable UI components.
- `src/hooks/`: Custom React hooks.
- `src/api/`: API client and related logic.
